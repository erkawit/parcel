# Technical Specification: ระบบออกเอกสาร "แจ้งขอซื้อ" (Request to Buy)

เอกสารฉบับนี้อธิบายรายละเอียดการพัฒนาฟังก์ชันการออกเอกสาร Word (.docx) สำหรับการ **"แจ้งขอซื้อ"** โดยใช้ Template และการแทนที่ตัวแปร (Variable Substitution)

---

## 1. การตั้งค่าไฟล์และโฟลเดอร์ (File Configuration)

### 1.1 ไฟล์ต้นฉบับ (Template)

- **ชื่อไฟล์:** `template_request_buy.docx`
- **ที่อยู่ (Path):** `templates/`
- **คำสั่ง:** โปรแกรมต้องอ่านไฟล์ Template นี้ให้ละเอียดก่อนทำการประมวลผล

### 1.2 การจัดเก็บไฟล์ผลลัพธ์ (Output Storage)

- **โฟลเดอร์หลัก:** `templates/`
- **โฟลเดอร์ปลายทาง:** `templates/word_jobs/`
  > **Note:** หากยังไม่มีโฟลเดอร์ `word_jobs` ให้ระบบทำการสร้างโฟลเดอร์นี้ขึ้นมาโดยอัตโนมัติ
- **รูปแบบชื่อไฟล์ (Naming Convention):**
  `{ชื่อผู้ใช้งาน}_{วันเดือนปี}_{เวลา}.docx`
  _ตัวอย่าง:_ `admin_13022026_1530.docx`

---

## 2. การจับคู่ตัวแปร (Data Mapping)

ตารางแสดงการจับคู่ระหว่างตัวแปรใน Word Template (`${...}`) กับข้อมูลในระบบ

| ตัวแปร (Placeholder)                      | แหล่งข้อมูล (Source)       | เงื่อนไข / คำอธิบาย (Logic)                                                                                   |
| :---------------------------------------- | :------------------------- | :------------------------------------------------------------------------------------------------------------ |
| `${court}`                                | DB: `system_settings`      | ดึงข้อมูลจากฟิลด์ `agency_name`                                                                               |
| `${date_create}`                          | DB: `maintenance_requests` | ดึงวันที่ที่มีการนำเข้าข้อมูลในตารางแจ้งซ่อม                                                                  |
| `${full_name}`                            | Session / Auth             | ดึงชื่อ-นามสกุล ของผู้ใช้งานที่ล็อกอินอยู่ในขณะนั้น                                                           |
| `${position}`<br>`${position_level}`      | DB: `users`                | ดึงข้อมูลตำแหน่ง และระดับตำแหน่ง ของผู้ใช้งานที่ล็อกอิน                                                       |
| `${asset_name}`<br>`${asset_description}` | **Condition (Logic)**      | **กรณีซ่อม:** ดึงชื่อ/รุ่น จากข้อมูลครุภัณฑ์ที่เลือก<br>**กรณีขอซื้อ:** ดึงข้อมูลจากการกรอกฟอร์ม (Input Text) |
| `${details_maintain}`                     | Form Input (Textarea)      | **คำเตือน:** ระบบต้องระบุให้ผู้ใช้ทราบว่า "กรุณากรอกข้อมูลด้วยภาษาราชการ" (เพื่อใช้ในการออกบันทึกข้อความ)     |
| `${director}`                             | DB: `users`                | Query หาผู้ใช้งานที่มี `position` = "ผู้อำนวยการฯ"                                                            |
| `${details}`                              | Form Input (Textarea)      | **Constraint:** เป็นช่องบังคับกรอก (Required) ระบุเหตุผลที่ต้องการขอซื้อ                                      |
| `${asset_volume}`                         | Form Input (Number)        | ระบุจำนวนที่ต้องการซื้อ                                                                                       |
| `${type_asset}`                           | DB: `type_volume`          | แสดงผลหน้าฟอร์มเป็น **Select Option** (ดึงหน่วยนับจากตาราง)                                                   |
| `${details_buy}`                          | Form Input (Textarea)      | **คำเตือน:** ระบบต้องระบุให้ผู้ใช้ทราบว่า "กรุณากรอกข้อมูลด้วยภาษาราชการ" (ใช้ประกอบเหตุผลในการซื้อ)          |

---

## 3. ขั้นตอนการทำงานของระบบ (Process Workflow)

1.  **ตรวจสอบ Template:** ระบบทำการโหลดไฟล์ `templates/template_request_buy.docx` เพื่อตรวจสอบความถูกต้องของ Tags
2.  **รับข้อมูล (Input Data):** รับข้อมูลจาก Form และ Query ข้อมูลจาก Database ตามตาราง Data Mapping
3.  **แทนที่ข้อมูล (Data Injection):** นำข้อมูลที่ได้ ไปแทนที่ตัวแปร `${...}` ทั้งหมดในไฟล์ Template
4.  **สร้างและบันทึกไฟล์ (Save File):**
    - สร้างชื่อไฟล์ตามรูปแบบ: `[User]_[DDMMYYYY]_[Time].docx`
    - บันทึกไฟล์ลงใน `templates/word_jobs/`
5.  **ดาวน์โหลด (Download):** สั่งให้ Browser ทำการดาวน์โหลดไฟล์ที่ถูกสร้างขึ้นมาใหม่ทันที

---

## 4. ข้อกำหนดส่วนติดต่อผู้ใช้งาน (UI Requirements)

- **Input Form:**
  - ช่อง `${details}` ต้องมีเครื่องหมายดอกจัน (\*) หรือการแจ้งเตือนว่าเป็นช่องบังคับ
  - ช่อง `${type_asset}` ต้องเป็น Dropdown List
- **Instruction Text:**
  - บริเวณช่องกรอก `${details_maintain}` และ `${details_buy}` ต้องมีข้อความกำกับชัดเจนเรื่อง **"การใช้ภาษาราชการ"**

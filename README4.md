# Specification: ระบบติดตามสถานะแจ้งซ่อม/จัดซื้อ (Public Tracking Page)

เอกสารฉบับนี้ระบุรายละเอียดการพัฒนาหน้าเว็บสำหรับแสดงรายการและรายงานผลการดำเนินงานแจ้งซ่อมและจัดซื้อ โดยเป็นหน้าระบบสาธารณะ (Public Page) ที่ไม่ต้องมีการ Login

---

## 1. ข้อมูลทั่วไป (General Info)

- **URL:** `http://localhost/parcel/tracking` (หรือชื่อไฟล์ตามความเหมาะสม)
- **Access Level:** Public (เข้าถึงได้โดยไม่ต้อง Login)
- **Theme:** ใช้ Theme และ Color Scheme เดียวกับระบบหลัก (Parcel System)

## 2. ส่วนแสดงผลตารางข้อมูล (Data Table)

หน้าเว็บจะต้องแสดงข้อมูลในรูปแบบ **Data Table** ที่สามารถสืบค้น (Search) และเรียงลำดับข้อมูลได้ โดยมีรายละเอียดคอลัมน์ดังนี้:

| คอลัมน์               | รายละเอียด               | การคำนวณ/เงื่อนไข                                                              |
| :-------------------- | :----------------------- | :----------------------------------------------------------------------------- |
| **วันที่แจ้ง**        | วันที่และเวลาที่ทำรายการ | Format: `d/m/Y H:i`                                                            |
| **ประเภท**            | แจ้งซ่อม / แจ้งซื้อ      | แสดงเป็น Badge สีแยกประเภท                                                     |
| **ผู้แจ้ง**           | ชื่อ-นามสกุล ผู้แจ้ง     | -                                                                              |
| **รายการ**            | ชื่อวัสดุ/ครุภัณฑ์       | -                                                                              |
| **อาการ/เหตุผล**      | รายละเอียดการแจ้ง        | -                                                                              |
| **ระยะเวลาดำเนินการ** | จำนวนวันที่ผ่านไป        | คำนวณจาก: `CurrentDate - CreateDate`<br>_(เช่น "3 วัน", "รอมาแล้ว 5 ชั่วโมง")_ |
| **สถานะ**             | สถานะปัจจุบัน            | รอตรวจสอบ / กำลังดำเนินการ / เสร็จสิ้น                                         |
| **จัดการ**            | ปุ่ม "รายงานผล"          | ปุ่มสำหรับกดเพื่อเปิด Modal/SweetAlert                                         |

### ฟังก์ชันเพิ่มเติมในตาราง

- **Search Bar:** ค้นหาได้จาก ชื่อผู้แจ้ง, รายการ, หรือเลขที่ใบแจ้ง
- **Highlight:** หากระยะเวลาดำเนินการเกินกำหนด (เช่น เกิน 3 วัน) ให้แสดงสีแถวเป็นสีแดงหรือเหลืองเพื่อแจ้งเตือน

---

### 3.1 การออกแบบ (Design)

- **Theme:** ใช้โทนสีหลักของหน่วยงาน/ระบบ ดูสะอาดตา (Clean UI)
- **Header:** ข้อความ "บันทึกผลการดำเนินงาน"
